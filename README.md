# ระบบบริหารจัดการและแจ้งเตือนวันหมดอายุการรับประกันอุปกรณ์ (WarrantyGuard)

**กลุ่ม:** Ultrasmooth

**สมาชิก:**  
- 68023414 ภูตะวัน เชียงตุง
- 68023469 วศิน ยาทิพย์

## ฟีเจอร์หลัก
- **Equipment Management:** จัดการข้อมูลอุปกรณ์ เลข Serial Number และรูปใบเสร็จ
- **Status View:** แสดงแถบเวลาและเปอร์เซ็นต์ความคุ้มครองเรียลไทม์
- **Automated Tracker:** ตรวจจับวันหมดอายุอัตโนมัติ และปรับสถานะเป็นหมดประกัน
- ตรวจสอบโควตาอุปกรณ์ในระบบสูงสุด 50 รายการ
- ระบบแจ้งเตือนล่วงหน้า 7 วัน และ 15 วัน
