# ระบบบริหารจัดการและแจ้งเตือนวันหมดอายุการรับประกันอุปกรณ์ (WarrantyGuard)

**กลุ่ม:** Ultrasmooth[cite: 1]
**สมาชิก:**  
- 68023414 ภูตะวัน เชียงตุง[cite: 1]
- 68023469 วศิน ยาทิพย์[cite: 1]

**เสนอ:** ดร.ณัฐพล หาญสมุทร[cite: 1]  
**รายวิชา:** พื้นฐานของระบบฐานข้อมูล[cite: 1]  
สาขาวิศวกรรมซอฟต์แวร์ คณะเทคโนโลยีสารสนเทศและการสื่อสาร มหาวิทยาลัยพะเยา[cite: 1]  

## ฟีเจอร์หลัก (Features)
- **Equipment Management:** จัดการข้อมูลอุปกรณ์ เลข Serial Number และรูปใบเสร็จ[cite: 1]
- **Status View:** แสดงแถบเวลาและเปอร์เซ็นต์ความคุ้มครองเรียลไทม์[cite: 1]
- **Automated Tracker:** ตรวจจับวันหมดอายุอัตโนมัติ และปรับสถานะเป็นหมดประกัน[cite: 1]
- ตรวจสอบโควตาอุปกรณ์ในระบบสูงสุด 50 รายการ[cite: 1]
- ระบบแจ้งเตือนล่วงหน้า 7 วัน และ 15 วัน[cite: 1]
